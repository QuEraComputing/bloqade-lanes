Text (.sst) codec for the vihaco-backed ISA.

A program is vihaco’s sst v1 section container holding one root section: a .header(root) block carrying the version, and a .text(root) block carrying fn @main(). parse_text shows the full shape.

Both halves are vihaco’s own grammar. [SstFile] frames the container and [ParsedModule::parse_section] parses the functions inside it; this module reads the version header itself (see parse_version_header) and lowers the parsed surface instructions into a Program via machine::lower.

vihaco ships a reader for this container and no writer, so to_text emits it via super::container::to_sst.
